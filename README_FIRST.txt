WORKBENCH CONTINUITY v1.2.0 — PUBLIC

1. Open Workbench_Continuity_v1.2.0_PUBLIC.html on a laptop, or install the
   Workbench_Continuity_v1.2.0_PUBLIC.apk on Android 9 or newer.
2. For build tools, double-click SETUP_WORKBENCH.bat on Windows once.
   Read Google's SDK agreement and decide whether to accept it.
3. In Workbench choose Load build runtime. Select the new ZIP from
   vendor/android-build-capsule/Private_Capsules. Keep that ZIP.

No separate Android Build Capsule download is needed. The proven setup is
included inside this Workbench download. Existing public Capsule runtimes
also work. Setup requires internet; Workbench then works locally/offline.

Open project → enter the next action → choose destination → Prepare.
For Claude/Grok, extract the bundle and follow its START_HERE.txt.
Attach every listed runtime and project part to the receiving chat.
The chat needs code execution; carrying tools does not grant that access.

On Android, use Sign returned APK to sign with your own project key privately.
Keep keys outside Open project/Add files and outside all AI uploads.

This public Android app installs alongside the earlier owner-private app.
Transfer projects using a saved work packet; keep the earlier installation.

Share this public download. Keep generated SDK runtimes, destination bundles,
your own projects and signing keys private unless separately cleared to share.
