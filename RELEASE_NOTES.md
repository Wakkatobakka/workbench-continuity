# Workbench Continuity v1.2.0 — Public Preview

Carry your actual project, build tools and working context into the next chat. Workbench includes the proven public Build Capsule setup, so users do not need to download a second product.

- Existing project engine, intake, notes, file carriage and local private signing behavior retained.
- Included first-time Windows setup creates each person's private runtime; Workbench loads and verifies it separately from their projects.
- Claude PDF and Grok ZIP bundles carry the current project and that verified runtime.
- Owner-private signing keys, runtime carriers and QA projects excluded from public files.
- Public Android app installs alongside the owner-private edition. Android 9 or newer required.

Source compilation, signature verification, private-signer host checks and emitted-route checks are recorded in VERIFICATION.md. A fresh physical-device run of this public APK and fresh external Claude/Grok chat runs remain unobserved. The included Windows setup machinery has prior owner-tested setup-to-build evidence; this preparation did not run its Windows dialog anew.
